EmuSwitch

A free, open-source emulator launcher for Nintendo Switch homebrew. Play 3DS games with the built-in 3DS emulator, and ten more consoles from the same menu.

Download EmuSwitch.nro Source on GitHub

The latest release, straight from GitHub. All releases

EmuSwitch is still in testing and doesn't fully work yet. Expect bugs, crashes and games that don't run properly.

Eleven consoles

3DS games run in EmuSwitch itself. The other consoles' emulators are packed inside EmuSwitch, so there's nothing else to install. Put games you own and dumped yourself in their console's folder on the SD card.

What's inside

Home and Systems

Games grouped by console with box art, which downloads automatically while you're online. You can also pick pictures from the SD card or from SteamGridDB. Reorder consoles and games as you like.

42 themes

Pick a colour theme in Settings. It changes the menus and the in-game quick menu together.

Simple settings

Each page shows the settings people change. Press X to see every setting, or search for any of them by name.

Save states and backups

Save and load states from the quick menu. Back up 3DS saves in Checkpoint's format, so they move between EmuSwitch and a real 3DS.

Made for 3DS on Switch

Screen layouts on R3, touch with a pointer, gyro, cheats, mods, texture packs, amiibo, upscaling and 1080p docked.

Updates itself

Settings, General, Check for Updates: EmuSwitch downloads the new version, checks it, and installs it as it restarts.

Install

You need a Switch that runs homebrew.

  1. Download EmuSwitch.nroFrom the latest release on GitHub.
  2. Copy it to the /switch/ folder on your SD cardEmuSwitch keeps its settings, 3DS saves and logs in /switch/dekopon/, the same folder Dekopon uses, so an existing Dekopon setup carries over.
  3. Open it from the Homebrew MenuThen put your games in their console's folder (see above).

If you're on 3.0.0-RC9 or older, install the next version by hand once. Those versions couldn't replace their own file while running.
